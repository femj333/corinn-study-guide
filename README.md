## Corinn's Study Guide

# Setup (only the first time)
Open your terminal
1. type`mkdir fems_super_cool_study_guide` hit enter
2. type `cd fems_super_cool_study_guide` hit enter
3. type `git clone ` hit enter
4. type `cd corinn-study-guide` hit enter
5. type `python main.py` hit enter

# Using the study guide
From here you can run the study guide all the way through. Each time you run through it will take a random path. If you keep your terminal open, just type `python main.py` and hit enter to run the game again. If you close your terminal, the next time you open it you will have to do this:
1. type `cd fems_super_cool_study_guide` hit enter
2. type `cd corinn-study-guide` hit enter
3. type `python main.py` hit enter
